Niveles de especificidad

Cuando dos reglas CSS chocan, el navegador elige la que tenga mayor especificidad, no la que esté más abajo.

¿Qué es la especificidad?

Un mismo elemento puede recibir varias reglas CSS que cambian la misma propiedad, por ejemplo dos colores distintos para un mismo párrafo. La especificidad es el sistema con el que el navegador decide cuál regla gana. Cada selector tiene un valor de prioridad, y el valor más alto se aplica.

Valores de prioridad

Tabla de pesos

El valor se escribe con 5 números, de mayor a menor importancia: !important, estilo en línea, id, clase y elemento.

Tipo de selector Ejemplo Valor
!important color: red !important; 1, 0, 0, 0, 0
Estilo en línea <p style="color:red"> 0, 1, 0, 0, 0
Id #titulo 0, 0, 1, 0, 0
Clase, pseudo-clase o atributo .caja, :hover, [type="text"] 0, 0, 0, 1, 0
Elemento o pseudo-elemento p, h1, ::before 0, 0, 0, 0, 1
Selector universal * 0, 0, 0, 0, 0

Cómo se comparan

Los valores se comparan de izquierda a derecha. Gana el primer número que sea mayor y los demás ya no importan. Por eso 1 id siempre vence a 100 clases: cada columna es independiente y no se suman entre ellas.

Ejemplos calculados

Selector Cálculo Valor
p 1 elemento 0, 0, 0, 0, 1
p.demo-p 1 clase + 1 elemento 0, 0, 0, 1, 1
nav a:hover 1 pseudo-clase + 2 elementos 0, 0, 0, 1, 2
#demo .demo-p 1 id + 1 clase 0, 0, 1, 1, 0

Ejemplo en vivo

.demo-p { color: #d63384; }   /* 0, 0, 0, 1, 0 */
p.demo-p { color: #198754; }  /* 0, 0, 0, 1, 1 → gana */

Este texto es verde porque p.demo-p es más específico que .demo-p.

Buenas prácticas

Usa clases en vez de ids para dar estilo. Evita !important y el estilo en línea. Si dos reglas tienen el mismo valor, gana la que aparece al final del archivo.
